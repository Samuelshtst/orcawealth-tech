`# Persona: Budi Santoso, 28`  
`*(Segmen B2C - Pengguna Akhir / Karyawan)*`

`## Profil`  
`- **Pekerjaan:** Karyawan swasta (Staf Operasional)`  
`- **Penghasilan:** Rp 6.500.000 per bulan`  
`- **Perangkat:** Smartphone Android 6,5 inci kelas menengah (sering dioperasikan dengan satu tangan)`  
`- **Konteks:** Literasi finansial masih di tahap dasar; sering mengonsumsi konten edukasi finansial di media sosial, namun kesulitan mengeksekusi niat menabung secara konsisten.`

`## Tujuan`  
`- Memiliki dana darurat yang aman dan terus bertumbuh.`  
`- Mengumpulkan dana untuk masa depan (misal: menikah atau DP rumah) secara terotomasi tanpa perlu mengingat jadwal transfer bulanan.`  
`- Berinvestasi dengan cara yang praktis dan tidak menyita waktu kerja.`

`## Pain point`  
`- Sering lupa atau menunda menyisihkan gaji, sehingga uang habis untuk pengeluaran konsumtif harian.`  
`- Sangat takut rugi dan mudah panik (*panic selling*) ketika melihat grafik pasar saham menurun.`  
`- Aplikasi sekuritas ritel pada umumnya dirasa terlalu rumit, penuh jargon teknis, dan mengintimidasi.`

`## Kutipan`  
`> "Saya sebenarnya ingin rutin investasi setiap gajian, tapi uangnya selalu keburu habis duluan. Sekalinya mencoba investasi, saya malah panik saat angkanya turun."`

`## Implikasi desain`  
`- **Invisible Investing:** Proses pengaturan potong gaji (*Orca Stream*) harus sangat singkat (maksimal 3 kali ketuk) dan *frictionless*.`  
`- **Goal-Based Tracking:** Layar utama (Beranda) difokuskan pada *progress bar* pencapaian tujuan (misal: Dana Pensiun 45%), bukan grafik *candlestick* atau pergerakan harga harian.`  
`- **Behavioral Nudging:** Implementasi *pop-up* pencegat (Orca Sonar) dengan *micro-copy* yang menenangkan (tidak menggunakan tombol warna merah agresif untuk penarikan dana).`  
`- **Aksesibilitas:** Menempatkan tombol *Call-to-Action* (CTA) utama di zona jempol (bagian bawah layar).`

`# Persona: Sarah, 42`  
`*(Segmen B2B - Pembuat Keputusan / HR Manager Korporasi)*`

`## Profil`  
`- **Pekerjaan:** Human Resources (HR) Manager di perusahaan ritel skala menengah (± 1.500 karyawan).`  
`- **Perangkat:** Laptop/Desktop kantor resolusi layar lebar (1080p ke atas).`  
`- **Konteks:** Sedang ditugaskan oleh jajaran direksi untuk menekan tingkat *turnover* (karyawan keluar) melalui perbaikan program fasilitas kesejahteraan karyawan (*Employee Benefit*).`

`## Tujuan`  
`- Meningkatkan loyalitas dan retensi karyawan tanpa membebani arus kas (CAPEX/OPEX) perusahaan.`  
`- Mendapatkan metrik dan data yang konkret untuk menunjang pelaporan pilar Sosial pada Laporan Keberlanjutan (ESG) tahunan perusahaan.`  
`- Mengimplementasikan fasilitas baru dengan mulus tanpa mengganggu alur *payroll* yang sudah ada.`

`## Pain point`  
`- Anggaran perusahaan sedang ketat, sehingga opsi kenaikan gaji massal atau pemberian bonus tunai tidak memungkinkan.`  
`- Tim HR sudah kewalahan dengan beban administrasi; enggan mengadopsi sistem baru yang butuh input manual berulang.`  
`- Kekhawatiran mengenai kepatuhan hukum (UU PDP) jika perusahaan terlalu jauh mengakses data privasi/keuangan individu karyawan.`

`## Kutipan`  
`> "Saya butuh program benefit yang memberi dampak nyata untuk kesejahteraan karyawan dan citra perusahaan (ESG), tapi syarat mutlaknya: tidak boleh merepotkan tim HR dan tidak menguras anggaran perusahaan."`

`## Implikasi desain`  
`- **B2B Web Dashboard (Desktop-First):** Desain antarmuka difokuskan pada format dasbor web (*Orca Pod*) yang optimal di layar lebar dengan *sidebar* navigasi.`  
`- **Data Minimization & Aggregation:** Angka yang ditampilkan di layar HR harus murni data agregat anonim (misal: "Tingkat Partisipasi = 65%"), menghilangkan segala risiko eksposur saldo atau portofolio individu (kepatuhan UU PDP).`  
`- **One-Click Export:** Menyediakan tombol aksi utama "Ekspor Laporan ESG (PDF/Excel)" yang mudah ditemukan di layar utama dasbor.`  
`- **Modul Payroll Transformer:** Tampilan layar *upload* file harus jelas dengan panduan langkah per langkah untuk mengonversi data gajian mentah menjadi file *Bulk Investment* yang siap diunggah ke CMS Bank.`
